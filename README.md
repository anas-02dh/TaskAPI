# Connect the API to PostgreSQL

This step replaces the in-memory JavaScript array with a PostgreSQL database while keeping the same layered architecture.

## Technologies

- Node.js
- Express.js
- PostgreSQL
- pg
- dotenv

## Install Dependencies

```bash
npm install pg dotenv
```

## Create the Database

Open PostgreSQL and create a database.

```sql
CREATE DATABASE tasks_db;
```

Connect to the database:

```sql
\c tasks_db
```

## Create the Tasks Table

```sql
CREATE TABLE tasks (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    done BOOLEAN NOT NULL DEFAULT FALSE
);
```

## Insert Sample Data

```sql
INSERT INTO tasks (name, done) VALUES
('Check in for work', true),
('Attend morning stand-up meeting', true),
('Reply to emails', false),
('Complete assigned tasks', false),
('Review pull requests', true),
('Join client meeting', false),
('Submit daily report', false),
('Check out at end of day', false);
```

Verify the data:

```sql
SELECT * FROM tasks;
```

## Configure Environment Variables

Create a `.env` file in the project root.

```env
PORT=3000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=tasks_db
DB_USER=your_username
DB_PASSWORD=your_password
```

## Database Connection

Create a connection pool using `pg`.

```javascript
require("dotenv").config();

const { Pool } = require("pg");

const pool = new Pool({
  host: process.env.DB_HOST,
  port: process.env.DB_PORT,
  database: process.env.DB_NAME,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
});

module.exports = pool;
```

## Repository Layer

The repository now executes SQL queries instead of reading from a JavaScript array.

Example:

```javascript
async findAll() {
    const result = await pool.query(
        "SELECT * FROM tasks ORDER BY id"
    );

    return result.rows;
}
```

## Service Layer

Since database operations are asynchronous, all service methods use `async/await`.

```javascript
async getAllTasks() {
    return await taskRepository.findAll();
}
```

## Controller Layer

Controllers also become asynchronous.

```javascript
async getAllTasks(req, res) {
    const tasks = await taskService.getAllTasks();
    res.status(200).json(tasks);
}
```

## A3 containerization with docker

# Dockerizing the Application

This project can be containerized using **Docker** and **Docker Compose**, allowing the Express API and PostgreSQL database to run in isolated containers.

## Prerequisites

- Docker
- Docker Compose

Verify the installation:

```bash
docker --version
docker compose version
```

---

## Project Structure

```text
.
├── docker/
│   └── init.sql
├── src/
├── Dockerfile
├── docker-compose.yml
├── .dockerignore
├── package.json
└── README.md
```

---

## Dockerfile

The application is built using the official Node.js Alpine image.

```dockerfile
FROM node:22-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY . .

EXPOSE 3000

CMD ["npm", "start"]
```

---

## .dockerignore

```text
node_modules
.git
.env
README.md
```

---

## Database Initialization

The `docker/init.sql` script automatically creates the `tasks` table and inserts sample data when the PostgreSQL container starts for the first time.

## Docker Compose

Build the Docker images:

```bash
docker compose build
```

Start the containers:

```bash
docker compose up
```

Run in detached mode:

```bash
docker compose up -d
```

Stop the containers:

```bash
docker compose down
```

Remove containers and database volume:

```bash
docker compose down -v
```
